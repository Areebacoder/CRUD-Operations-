# Student Record Management System (CRUD Operations)

## Programming Fundamentals – Assignment 4

### Description

This project is developed in **C++** to demonstrate **File Handling** using CRUD (Create, Read, Update, Delete) operations. The program stores student records in a text file named **students.txt**.

Each student record contains:

* Roll Number
* Student Name
* Marks

---

## Features

### 1. Create

* Creates a file named **students.txt**.
* Takes input for 5 students.
* Saves Roll Number, Name, and Marks into the file.

### 2. Read

* Reads all student records from **students.txt**.
* Displays the records on the console.
* Shows the total number of records.

### 3. Update

* Searches for a student using Roll Number.
* Updates the student's marks.
* Saves the updated record back to the file.

### 4. Delete

* Deletes a student's record using Roll Number.
* Uses a temporary file to remove the selected record.
* Updates the original file after deletion.

## How to Run

1. Open the project in any C++ IDE (Code::Blocks, Dev-C++, or Visual Studio).
2. Compile and run each program.
3. Create the file first by running **Q1_Create.cpp**.
4. Then run the Read, Update, and Delete programs.
